## Animations

### On Page Load:
- **Fade In**: Entire page fades in smoothly
- **Slide Up**: Sections slide up as you scroll
- **Float**: AWS icons in hero float up and down
- **Pulse**: "Available" indicator pulses

### On Hover:
- **Scale**: Buttons and icons scale up 110%
- **Shadow**: Cards get deeper shadows
- **Color**: Tech badges change color
- **Grayscale**: Images lose grayscale filter

### On Scroll:
- **Header**: Becomes solid white with shadow
- **Scroll Indicator**: Bounces in hero section

## Responsive Breakpoints

```
Mobile:    < 768px   - Single column, hamburger menu
Tablet:    768-1024px - Two columns, compact spacing
Desktop:   > 1024px   - Full layout, three columns
```

### Mobile View Changes:
- Hamburger menu instead of nav links
- Stacked hero content (text then image)
- Single column for all sections
- Smaller text sizes
- Touch-optimized buttons

## Typography

```
Headings:
- H1 (Hero name):  5xl-7xl (48-72px) Bold
- H2 (Sections):   4xl-5xl (36-48px) Bold
- H3 (Cards):      2xl-3xl (24-30px) Semibold
- H4 (Subsections): xl-2xl (20-24px) Semibold

Body:
- Large:  lg (18px) Regular
- Normal: base (16px) Regular
- Small:  sm (14px) Medium

Accent:
- Mono font for badges/labels
- Sans-serif for everything else
```

## Interactive Elements

### Buttons:
```
Primary (Orange):
- Background: #FF9900
- Hover: Darker orange + lift effect
- Icon + text

Secondary (Dark):
- Border: 2px solid #232F3E
- Hover: Border becomes orange
- Icon + text
```

### Cards:
```
- White background
- Subtle shadow
- Rounded corners (xl = 12px)
- Border on hover (orange)
- Scale up slightly on hover
```

### Links:
```
- Gray color default
- Orange on hover
- Smooth transition (300ms)
```
